# efrumos.md

Интернет-магазин косметики (Молдова): Laravel 10 + самописная CMS. Языки сайта:
ro (по умолчанию), ru, en. Рабочая ветка — `stage`, она же едет на dev.

## Задачи

`TASKS.md` — открытые задачи бекенда и фронтенда. Читай его, когда берёшь
задачу, и дополняй, когда находишь проблему, которую не закрываешь в текущем
коммите. Правила взятия, закрытия и шаблон — в начале файла.

## Что не видно из кода

- **База разворачивается из дампа**, а не миграциями: миграции есть только
  для новых таблиц и колонок. Правки структуры и данных CMS — идемпотентные
  SQL-патчи в `database/sql/`, применяются `php artisan db:apply-sql-patches`
  (деплой вызывает его после `migrate`).
- **Шаблоны кешируются**: после правок blade выполняй `php artisan view:clear`,
  иначе изменения не видны.
- **`LANG` и `LANG_ID`** определяет middleware `SetLocale`. В artisan, tinker,
  очередях и обработчике исключений их нет — бери язык из запроса или конфига.
- **Деплой** (`bin/server-deploy.sh`) не синкает `.env`, `php-conf.d`,
  `docker*`, `public/upfiles`. Серверные настройки меняются руками — такие
  шаги оформляй задачей `[DevOps]` в `TASKS.md`.
- **Статус оплаты заказа** меняется только через `OrderPaymentStatusService`:
  он проверяет переход и пишет журнал. Статус решает server callback банка,
  BACKREF только читает его.
