## 8. Грабли

- **SSH к dev:** сам `bin/server-deploy.sh` (одна сессия) обычно проходит, а
  отдельные подключения вне деплоя хост отклоняет (`Permission denied`) часами.
  Не долбить повторами. Не использовать `docker restart` на серверах — только
  `docker kill --signal=USR2`.
- **Puppet** на хосте (`/etc/puppetlabs`) откатывает ручные правки
  `php-conf.d/php-fpm.ini` — лимиты поэтому в отдельном файле через деплой.
- **Локальный docker:** контейнеры часто выключены. Порт БД 3306 занят чужим
  проектом `gocon` — БД efrumos поднимать через override с портом 3307
  (файл вне репозитория):
  ```
  printf 'services:\n  db:\n    ports: !override\n      - "127.0.0.1:3307:3306"\n' > /tmp/compose-db-3307.yml
  docker compose -f docker-compose.yml -f /tmp/compose-db-3307.yml --profile local-db up -d db app nginx redis queue scheduler node
  docker network connect --alias db --alias efrumos-db-1 efrumos_default efrumos-db-1   # если приложение не видит db
  ```
  Redis из app-контейнера не резолвится (dispatch в очередь падает) — в API
  приложения сбой очереди перехвачен, заказ создаётся.
- **Локальный `.env`:** `AMOCRM_ENABLED=false` (не слать тестовые заказы в
  Platon/Progression!), `ONEC_MOCK_MODE=false` (осторожно: реальные вызовы 1С
  тестовой базы; на тест включать `true` временно), локальные
  `ONEC_STATUS_WEBHOOK_TOKEN` и `APP_API_TOKEN` (только для локали).
- **git-bash/Windows:** `curl -d '{...}'` с кавычками ломает JSON — слать через
  файл `--data-binary @file`; `python` нет; `/tmp` в `docker exec` писать через
  `sh -c`; `LANG_ID` в tinker задавать `define('LANG_ID', 3)`.
- **Локальная БД изменена (не для коммита):** `shops_id.store_guid` у 10/11/12/13,
  `goods_shop_rests` 34 880 строк (полный обмен 1С), тестовые фото оттенков у
  товаров 952–957 (`public/upfiles/goods-shades/`).
- Заказ из приложения не привязан к `front_user` — только к `client_id`.
- Не путать: `orders.onec_order_status` (бизнес-статус 1С) и
  `integration_id_mappings.onec_status` (наш статус синхронизации).
