# Changelog

## Epic 2 — Магазины (карта, список, геолокация)

- Страница «Магазины»: карта на Leaflet, список с группировкой по городу,
  сортировка по расстоянию (геолокация браузера), кнопка «Построить маршрут».
- Координаты магазинов заведены в БД (`database/sql/2026-09-01-shops-coordinates.sql`).
- Новая карточка товара по макету Figma (все брейкпоинты), палитра оттенков,
  остатки по складам 1С на карточке товара.
- Выбор магазина самовывоза при оформлении заказа.

## Epic 1 — Оплата и интеграционный слой (1С / Bitrix24 / VictoriaBank)

- Онлайн-оплата через VictoriaBank e-Gateway: инициализация платежа, редирект,
  обработка результата (Ok/Fail/processing), сверка статусов.
- Интеграционный слой сайт↔1С↔Bitrix24: приём заказа, проверка/резерв товара,
  передача статуса оплаты, сделка в Bitrix24, ручное закрепление статуса в CMS,
  обработка десинхронизации и уведомление на почту.
- Задача сотруднику + уведомление в Bitrix24 после подтверждённой оплаты
  (`tasks.task.add`, `im.notify`, `crm.timeline.comment.add`).
- `INTEGRATION_MOCK_MODE` (`services.integration.mock_mode`, по умолчанию
  `true`) — единый флаг, мокающий все вызовы к 1С/Bitrix24 (проверка остатка,
  резерв, отметка оплаты, сделка, статус сделки, задача/уведомление), пока нет
  реального доступа к их API. При `false` — честное поведение: реальная
  проверка остатка из БД, `IntegrationGatewayException` на каждой записи.
- `AMOCRM_ENABLED` (`services.amocrm.enabled`, по умолчанию `true`) — флаг для
  `SendOrderToAmoCrm`, который несмотря на название реально стучится в
  `platon.progression.md` (не AmoCRM) с боевым токеном; выключен локально по
  умолчанию, чтобы тестовые заказы туда не улетали.
- Докеризация локального окружения (`docker-compose.yml`, `Dockerfile`,
  `bin/local-up.sh`, `bin/server-deploy.sh`, `DOCKER.md`).

`efrumos-docs/` (вне репозитория).
